# Среда разработки

## Purpose

Единая воспроизводимая среда для домашних заданий курса Simple Architecture.

## Requirements

### Requirement: Запуск приложения

Проект MUST запускать React 19 в StrictMode, компилировать TypeScript 7 через Rsbuild и поддерживать стили в CSS Modules.

#### Scenario: Локальная разработка

- **WHEN** разработчик устанавливает зависимости закреплённой версией pnpm и запускает `pnpm dev`
- **THEN** браузер открывает приложение, а изменения исходников отображаются без ручной пересборки

### Requirement: Запросы и кеширование

Приложение MUST использовать Axios для HTTP-запросов и SWR для кеширования данных.

#### Scenario: Стартовый каталог

- **WHEN** пользователь открывает главную страницу
- **THEN** приложение загружает локальный каталог и отображает сериалы

### Requirement: Проверки проекта

Команда `pnpm check` MUST проверять формат через Oxfmt, типы через Oxlint и ограничивать написанные вручную текстовые файлы 120 строками.

#### Scenario: Превышение лимита

- **WHEN** исходный файл после форматирования содержит 121 строку
- **THEN** команды форматирования и проверки сообщают об ошибке и указывают файл

### Requirement: Настройки рабочей области

Проект MUST хранить правила агентов и настройки VS Code в репозитории.

#### Scenario: Форматирование импортов

- **WHEN** разработчик сохраняет файл JavaScript или TypeScript в VS Code или запускает `pnpm format`
- **THEN** импорты идут в порядке React и React DOM, сторонние библиотеки, внутренние модули, `import type`, стили. В каждой группе пути идут по алфавиту
- **AND** типы из смешанных импортов попадают в общий блок `import type` независимо от модуля. Если стилей нет, блок типов идёт последним
- **AND** между непустыми группами остаётся одна пустая строка, а между последним импортом и кодом — две

#### Scenario: Подписи вкладок

- **WHEN** разработчик открывает файлы `index.tsx`, `usePresenter.ts` и `styles.module.css` из папки `Catalog` в VS Code
- **THEN** вкладки подписаны `Catalog/index`, `Catalog/usePresenter` и `Catalog/styles`
