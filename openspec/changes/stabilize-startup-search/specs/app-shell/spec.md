## ADDED Requirements

### Requirement: Индикация запуска

Оболочка MUST показывать индикатор Season One с первого отображения документа и заменять его каталогом, когда готов интерфейс на начальном языке.

#### Scenario: Медленное соединение

- **WHEN** HTML получен, а скрипты, стили каталога или начальный перевод ещё загружаются
- **THEN** виден фирменный знак загрузки, не требующий внешних ресурсов или JavaScript для анимации
- **AND** при появлении каталога индикатор исчезает без дополнительной задержки

#### Scenario: Уменьшенное движение

- **WHEN** пользователь предпочитает уменьшенное движение
- **THEN** виден неподвижный знак; состояние загрузки доступно также для скринридера

### Requirement: Стабильный текст поиска при загрузке

Поздняя загрузка шрифтов MUST сохранять положение видимого поля, его подсказки и введённого текста.

#### Scenario: Шрифты приходят после первого отображения поиска

- **WHEN** посетитель видит поле до завершения загрузки шрифтов
- **THEN** оно уже доступно для ввода, а после прихода шрифтов надпись не смещается и не меняет ширину
