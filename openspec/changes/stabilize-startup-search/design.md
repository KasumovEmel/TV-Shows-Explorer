## Context

В шаблоне пустой корневой элемент. Начальные скрипты и таблица стилей загружаются до показа поиска, а русская локаль может требовать ещё одного запроса. В записи ширина букв подсказки меняется без движения рамки: оба шрифта используют позднюю подмену.

## Goals / Non-Goals

- Показать обратную связь до запуска React и оставить поиск доступным независимо от скорости загрузки шрифтов.
- Сохранить существующие скелетоны выдачи и перемещение поля после ввода.

## Decisions

- Поместить знак с двумя треугольниками и подписью Season One в корень HTML. Критические стили идут в том же документе; анимация меняет только прозрачность и отключается при уменьшенном движении. React заменяет знак первым экраном без таймера.
- Загружать модуль каталога с его стилями параллельно с инициализацией языка. Тогда таблица стилей каталога не блокирует первый показ знака, но уже доступна при появлении поля.
- Использовать политику шрифтов без поздней подмены для Golos Text и Unbounded: запоздавший шрифт заголовка тоже может сдвинуть поле, изменив перенос строк. Ожидание всех шрифтов перед показом поиска на 3G задержало бы ввод.

## Risks / Trade-offs

- На медленном соединении первая страница может остаться с системным шрифтом до следующего открытия. Проверяем положение поля и рисунок подсказки до и после ответа на запросы шрифтов.
