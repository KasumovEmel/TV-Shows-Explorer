## Decisions

- После Oxfmt применять `import/newline-after-import` с `count: 2` к буферу редактора или ко всем форматируемым файлам за один запуск Oxlint. Комментарий в строке импорта сохранять рядом с ним.
- Эндпоинты вызывают `request()`. Oxlint ограничивает доступ к транспорту в `src/` и проверяет обработку исключений внутри общего клиента.
- Разрешить типы Axios и именованные функции проверки ошибок, которые использует SWR.
