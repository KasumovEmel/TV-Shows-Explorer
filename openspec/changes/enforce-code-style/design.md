## Context

CLI и VS Code уже вызывают один форматтер на базе Biome, Oxfmt и парсера Oxc. Поиск запрашивает TVmaze через Axios; SWR использует отклонённый промис для показа ошибки и повторного запроса.

## Decisions

- Использовать правило блоков на этапе Biome и поручить Oxfmt отступы. Вызовы хуков распознавать по синтаксическому дереву; сохранять привязку комментариев к инструкциям.
- После Oxfmt применять `import/newline-after-import` с `count: 2` к буферу редактора или ко всем форматируемым файлам за один запуск Oxlint. Комментарий в строке импорта сохранять рядом с ним.
- Использовать типизированные правила Oxlint для промисов. Эндпоинты вызывают `request()`. Oxlint ограничивает доступ к транспорту в `src/` и проверяет обработку исключений внутри общего клиента.
- Передавать ошибку поиска в SWR с контекстом операции и исходной причиной.

## Risks / Trade-offs

- Текстовая замена может изменить строки и комментарии. Проверить повторное форматирование, соседние хуки, комментарии и редакторский ввод через stdin.
