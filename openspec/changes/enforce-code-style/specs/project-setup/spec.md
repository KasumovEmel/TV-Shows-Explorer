## ADDED Requirements

### Requirement: Асинхронные операции

Oxlint MUST проверять использование общего клиента для запросов приложения и обработку ошибок внутри клиента.

#### Scenario: Ошибка запроса

- **WHEN** общий HTTP-клиент отправляет запрос через Axios
- **THEN** проверка требует дождаться запроса внутри `try` с соответствующим `catch`

#### Scenario: Новый эндпоинт

- **WHEN** эндпоинт вызывает `request()` из `@shared/utils/request`
- **THEN** проверка разрешает вызов без локального `try/catch`
- **WHEN** код приложения за пределами общего клиента подключает клиент Axios или использует браузерный `fetch` или `XMLHttpRequest`
- **THEN** Oxlint указывает использовать `request()`, даже если вызов обёрнут в `try/catch`
- **AND** типы Axios и именованная проверка `isAxiosError` доступны обработчику ошибок
