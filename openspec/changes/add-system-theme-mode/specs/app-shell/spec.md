## MODIFIED Requirements

### Requirement: Цветовая тема

Приложение MUST сохранять выбранный режим цветовой темы в локальном хранилище и применять его к индикатору загрузки, каталогу, уведомлениям и запасному экрану.

#### Scenario: Первый запуск

- **WHEN** пользователь впервые открывает приложение
- **THEN** сохраняется режим `system`, палитра соответствует настройкам устройства, а на кнопке видны солнце и луна через косую черту

#### Scenario: Смена темы

- **WHEN** пользователь меняет системную тему во время просмотра выдачи в режиме `system`
- **THEN** цвета меняются, текущий запрос, выбранный жанр и страница сохраняются

#### Scenario: Ручной выбор и возврат к системной теме

- **WHEN** пользователь нажимает кнопку темы
- **THEN** режим меняется по циклу «системный → тёмный → светлый → системный», сохраняется и восстанавливается после перезагрузки
- **AND** тёмный режим обозначен луной, светлый — солнцем, а подсказка на языке интерфейса сообщает текущий режим и следующее действие
- **AND** в ручном режиме палитра сохраняется при смене темы устройства, а при возврате к системному сразу применяется текущая палитра устройства
