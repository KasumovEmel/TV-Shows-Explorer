## Context

Кнопка темы находится в шапке поиска. Индикатор запуска появляется до React, а при ошибке рендера шапка размонтируется.

## Goals / Non-Goals

Сохранять выбор между посещениями и применять его ко всему документу, в том числе при отсутствии шапки.

## Decisions

- Использовать прежний ключ `tv-shows-explorer.theme`. Сохранённые значения `light` и `dark` остаются действительными. При первом запуске записывать `system`.
- Устанавливать режим на корневом элементе до первого отображения. Для системного режима браузер выбирает палитру через CSS и системный медиазапрос цвета панели браузера.
- Хранить хук кнопки внутри `AppHeader`. Нажатие выбирает следующий режим по циклу «системный → тёмный → светлый → системный». Иконка показывает текущий режим, подсказка и доступное имя также описывают следующее действие.

## Risks / Trade-offs

Если браузер запрещает запись в хранилище, выбранный режим действует до окончания текущего посещения.
