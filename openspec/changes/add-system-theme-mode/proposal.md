## Why

После ручного выбора палитры пользователь может вернуться к системной теме только очистив настройку браузера. Кнопка в шапке должна давать доступ ко всем трём режимам.

## What Changes

- При первом открытии сохранить системный режим. Восстанавливать выбранный режим при следующих посещениях.
- Добавить третий значок с солнцем и луной через косую черту. Показывать значок текущего режима и называть следующее действие в подсказке.

## Impact

Изменение затрагивает загрузочный экран, палитру приложения, шапку поиска, оба словаря и браузерные проверки.
