## Purpose

Локализация позволяет читать каталог на русском или английском и получать переводы по мере необходимости.

## ADDED Requirements

### Requirement: Начальный язык

Приложение MUST выбрать первый поддерживаемый язык из предпочтений браузера с учётом региональных вариантов. При отсутствии совпадений приложение MUST использовать английский.

#### Scenario: Русская локаль системы

- **WHEN** пользователь впервые открывает каталог с предпочтением `ru-RU`
- **THEN** интерфейс и демонстрационный каталог отображаются на русском

#### Scenario: Запасной язык

- **WHEN** среди предпочтений браузера нет русского и английского
- **THEN** каталог открывается на английском

### Requirement: Смена языка и загрузка словарей

Приложение MUST включать английский в начальную сборку и загружать русский отдельно только при первом обращении. Выбранный вручную язык MUST применяться без перезагрузки и сохраняться при доступном локальном хранилище.

#### Scenario: Английский при открытии

- **WHEN** начальный язык английский
- **THEN** браузер показывает английский интерфейс без запроса русского словаря

#### Scenario: Ручной выбор

- **WHEN** пользователь выбирает русский в английском интерфейсе
- **THEN** каталог, жанры, сообщения и язык HTML-документа переключаются на русский
- **AND** повторное переключение в том же сеансе использует уже загруженный словарь

#### Scenario: Повторное открытие

- **WHEN** пользователь открывает страницу после ручного выбора языка
- **THEN** приложение восстанавливает его выбор из локального хранилища
