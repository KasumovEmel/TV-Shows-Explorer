## Context

React получает единый каталог через Axios и SWR. Переключение языка должно переиспользовать эти данные.

## Goals / Non-Goals

Локализовать текущий экран, подписи для доступности, названия и жанры демонстрационных сериалов. Оригинальное название сохраняется в данных.

## Decisions

- Английский словарь входит в сборку. Динамический импорт русского словаря создаёт дополнительный файл, который загружается только для русского.
- i18next хранит загруженные ресурсы. Компоненты получают переводы через react-i18next.
- Сохранённый выбор имеет приоритет над `navigator.languages`. Региональные варианты сопоставляются с базовым языком.
- Ключ SWR общий для обоих языков. Переводы названий сериалов привязаны к идентификаторам.

## Risks / Trade-offs

При ошибке загрузки русского словаря остаётся доступным английский. Если браузер ограничивает локальное хранилище, переключатель работает до перезагрузки страницы.
