## Why

Стартовый каталог показывает все сериалы сразу. Для следующего задания нужен поиск, в котором пользователь сам задаёт запрос, сужает выдачу по жанру и просматривает её по три сериала.

## What Changes

- Главный экран начинается с одного поля поиска; карточки появляются после запроса.
- Над результатами появляются жанры всей выдачи и переключатель страниц. Прокрутка автоматически открывает следующие тройки в том же списке.
- В репозитории появляется визуальный эталон для настольного и мобильного экранов, состояний и будущей библиотеки компонентов.

## Capabilities

### New Capabilities

- `series-search`: поиск сериалов, выбор жанра, страницы и последовательная подгрузка.

### Modified Capabilities

- `project-setup`: запрос данных начинается после ввода пользователя, а не при открытии страницы.

## Impact

Макеты и правила компонентов находятся в `docs/design/`. При реализации изменятся представление и презентер каталога; для поиска потребуется источник результатов с массивом жанров. Выбор поставщика API не влияет на макеты.
