## Purpose

Пользователь находит сериалы по названию, уточняет выдачу по жанру и переходит к интересующей группе результатов.

## ADDED Requirements

### Requirement: Поиск по названию

Экран MUST начинаться с одного поля поиска, показывать только результаты текущего запроса и возвращаться в исходное состояние при очистке.

#### Scenario: Ввод и очистка

- **WHEN** пользователь вводит непустой текст
- **THEN** поиск запускается без отдельной кнопки, а результат содержит первую тройку или все найденные сериалы, если их меньше
- **WHEN** пользователь очищает поле или оставляет только пробелы
- **THEN** на экране остаётся только пустое поле; ответ прежнего запроса не возвращает карточки

#### Scenario: Ожидание, отсутствие совпадений и ошибка

- **WHEN** поиск выполняется, ничего не нашёл или завершился ошибкой
- **THEN** интерфейс различает эти состояния, сохраняет введённый текст и при ошибке позволяет повторить тот же запрос

### Requirement: Фильтр по жанру

Приложение MUST показывать над списком уникальные жанры всей текущей выдачи и позволять выбирать один жанр либо все.

#### Scenario: Жанр есть только на последней странице

- **WHEN** жанр встречается только у седьмого сериала
- **THEN** его тег доступен уже над первой тройкой; выбор тега показывает этот сериал на первой странице фильтра

#### Scenario: Сериал имеет несколько жанров

- **WHEN** выбран один из жанров сериала
- **THEN** сериал попадает в отфильтрованный список один раз, а остальные теги остаются доступны

#### Scenario: Сброс и смена запроса

- **WHEN** пользователь выбирает «Все» или вводит другой запрос
- **THEN** выбранный жанр сбрасывается; список и нумерация начинаются заново

### Requirement: Переключение страниц и автоматическая подгрузка

Приложение MUST делить отфильтрованную выдачу на страницы по три сериала, поддерживать переход по номеру и открывать следующую страницу при прокрутке без кнопки подгрузки.

#### Scenario: Прокрутка семи результатов

- **WHEN** пользователь доходит до нижней границы первой тройки, а затем второй
- **THEN** к списку последовательно добавляются ещё три карточки и одна последняя; ранее показанные карточки сохраняются без дублей, загрузка прекращается

#### Scenario: Переход по номеру

- **WHEN** пользователь выбирает страницу 3 до её появления или возвращается к странице 1
- **THEN** список показывает начало выбранной группы, отмечает её номер и сохраняет порядок результатов

#### Scenario: Одна страница

- **WHEN** в выдаче от одного до трёх сериалов
- **THEN** все они видны без переключателя страниц и без индикатора подгрузки
