# Design

## Context

Поиск TVmaze — единственный API-эндпоинт. В каталоге уже есть кнопка повтора для первой загрузки и отдельное уведомление о сохранённых данных при сбое обновления.

## Goals / Non-Goals

Функции эндпоинтов отвечают за параметры и преобразование ответа. Очередь уведомлений и тексты для пользователя остаются в слое интерфейса.

## Decisions

- Общий `request<T>()` дожидается ответа Axios, возвращает данные и при сбое добавляет контекст запроса, сохраняя исходную ошибку в `cause`. Тайм-аут клиента остаётся 10 секунд.
- Провайдер SWR внутри провайдера уведомлений выбирает сообщение в `onError`. Для 429 он читает статус из исходной ошибки Axios. Для остальных сбоев, включая отсутствие ответа, выбирает общий текст.
- Экран поиска сообщает только о показе сохранённой выдачи. Его кнопка повтора по-прежнему использует текущий ключ SWR.

## Risks / Trade-offs

Если оставить уведомление об ошибке также в презентере поиска, в очередь попадут два сообщения об одном сбое. Браузерная проверка должна пройти очередь после ошибки обновления.
