## ADDED Requirements

### Requirement: Уведомления об ошибках API

Приложение MUST показывать одно уведомление о сбое запроса на языке интерфейса и отличать превышение лимита запросов от остальных ошибок.

#### Scenario: Превышение лимита

- **WHEN** API отвечает HTTP 429
- **THEN** пользователь видит предупреждение с предложением подождать перед повтором

#### Scenario: Остальные ошибки

- **WHEN** запрос завершается с другим ошибочным статусом или без ответа сервера
- **THEN** пользователь видит общее уведомление об ошибке загрузки данных

#### Scenario: Ошибка обновления поиска

- **WHEN** запрос обновления завершается ошибкой, а в кеше уже есть выдача
- **THEN** сохранённая выдача остаётся на экране, и после уведомления о сбое появляется отдельное сообщение о показе сохранённых результатов
