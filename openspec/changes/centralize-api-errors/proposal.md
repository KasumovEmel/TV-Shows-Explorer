# Proposal

## Why

При ошибке TVmaze экран поиска выдаёт одинаковый совет и для ограничения частоты запросов, и для сбоя соединения. Следующим эндпоинтам нужна та же обработка без собственного блока `try/catch`.

## What Changes

- Все вызовы API используют общий типизированный `request()`.
- При HTTP 429 приложение предлагает подождать. Для остальных ошибок SWR показывает общее уведомление.
- Поиск сохраняет ручной повтор и ранее полученные результаты при сбое обновления.

## Impact

Изменение затрагивает запрос поиска TVmaze, корневую конфигурацию SWR, очередь уведомлений и словари приложения.
