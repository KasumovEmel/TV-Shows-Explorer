## Context

`PagedResults` хранит группы по три сериала и привязывает ссылки к началу группы. `LoadingCards` и готовые карточки уже используют общий компонент `ShowCardLayout`.

## Decisions

- Задать одну колонку для всех групп в общих стилях списка. Сохранить разметку групп, чтобы номера по-прежнему ссылались на тройки.
- Ограничить ширину постера и длину строк описания на широком экране. Скелетон использует ту же рамку, две линии описания и короткие заглушки названия и жанров. На узком экране описание по-прежнему располагается под миниатюрой.
- Проверять переходы в обычном и высоком окне: один жест у границы открывает одну группу, переход по номеру не открывает следующую страницу сам по себе.
- При прокрутке активна группа с наибольшей видимой долей собственной высоты под панелью. При равенстве остаётся более ранняя группа. Когда в окно входит нижний край последней карточки полной выдачи, активна последняя страница. При выборе номера браузер подводит группу к панели в пределах длины документа и сохраняет выбранный номер до следующей прокрутки.

## Risks / Trade-offs

- Текст разной длины может изменить высоту строки → разрешить перенос и рост карточки, фиксировать только рамку постера.
