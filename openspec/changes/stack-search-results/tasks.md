## 2. Пагинация и проверка

- [x] 2.1 Проверить раскладку на широком и узком экране, подгрузку у границы и выбор номера в обе стороны; устранить обнаруженные ошибки и выполнить проверки проекта.
- [x] 2.2 Воспроизвести пропуск третьей страницы при десяти результатах; исправить определение активной группы и проверить прокрутку в обе стороны.
- [x] 2.3 Убрать дополнительную высоту после списка и проверить последовательность номеров при обычной прокрутке и переходах по ссылкам до естественного конца страницы.
- [x] 2.4 Определять страницу по видимости карточек и проверять пересечение первой и второй групп, а также короткую последнюю группу до нижней границы окна прокрутки.
