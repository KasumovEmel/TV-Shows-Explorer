## ADDED Requirements

### Requirement: Переключатель языка

Кнопка с флагом MUST переключать русский и английский до ввода запроса и при просмотре результатов.

#### Scenario: Использование в узкой шапке

- **WHEN** пользователь активирует кнопку языка с клавиатуры на экране шириной 320 px
- **THEN** язык интерфейса и флаг меняются без потери запроса; у кнопки есть доступное имя и область нажатия не менее 44 × 44 px
- **AND** заголовок шапки целиком помещается в одну строку на обоих языках
