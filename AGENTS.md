# Работа в TV Shows Explorer

На компьютере автора следуй инструкциям для терминала из `~/.codex/RTK.md`.

Перед изменениями прочитай все Markdown-файлы верхнего уровня в [.agents/rules/](.agents/rules/). В них собраны правила курса для этого репозитория.

- Для рукописного кода клиента и сервера применяй правила SA по [структуре](.agents/rules/sa/sa-structure.md) и [именованию](.agents/rules/sa/sa-naming.md).
- При изменении React-клиента выбери в [указателе клиента](apps/web/AGENTS.md) правила для затронутых частей приложения и прочитай их. Все файлы `sa-*.md` лежат в [.agents/rules/sa/](.agents/rules/sa/).

Для каждого нового домашнего задания используй OpenSpec. Описание текущего поведения хранится в `openspec/specs/`, материалы отдельного изменения — в `openspec/changes/`.
