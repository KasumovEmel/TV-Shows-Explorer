# «Season One» · компоненты

[Визуальные образцы](screens/08-components.svg) · [Цвета и размеры](tokens.json) · [Все экраны](README.md)

## Цвет и шрифт

Тёплый молочный фон сочетается с лавандовой шапкой. Сливовая заливка выделяет текущую страницу, фисташковая заливка и галочка отмечают выбранный жанр. Для клавиатурного фокуса используйте тёмную обводку на светлом фоне и светлую на тёмном. [Тёмная тема и системные компоненты](system-components.md).

Unbounded задаёт форму логотипа, заголовка «Что посмотрим?» и названий сериалов. Golos Text используется в поле, тегах и подписях. В узких контейнерах длинный заголовок переносится, а шапка растёт по высоте.

## SearchField

Один элемент ввода на всём пути от [старта](screens/02-initial.svg) до [выдачи](screens/01-results.svg). Высота 62 px на широком экране, 52 px на узком. Лупа — знак внутри поля. При вводе справа появляется кнопка «Очистить поиск» с зоной нажатия 44 × 44 px.

Пустое поле показывает «Найти сериал». У поля есть постоянное доступное имя «Поиск сериалов». Короткая пауза после ввода запускает поиск; Enter отправляет его сразу. При очистке фокус остаётся в поле. Начальное состояние не содержит брендинга, пояснений, жанров или истории.

## GenreChip

Над результатами — тег «Все», затем по одному тегу для каждого жанра в порядке первого появления во **всём** ответе. Пустые и повторяющиеся значения пропускаются. Один жанр активен одновременно. Если ни у одного сериала нет жанров, строка тегов не нужна.

Высота 44 px; текст и галочка помещаются без обрезки. По умолчанию выбрано «Все». Активный тег отличается заливкой и галочкой; на клавиатурном фокусе появляется внешняя обводка. Кнопки доступны по Tab, работают по Enter и пробелу, передают состояние через `aria-pressed`.

При выборе жанра считать и нумеровать отфильтрованные результаты с первой страницы. Смена запроса сбрасывает жанр. «Все» возвращает исходный порядок и первую тройку.

## ShowCard

Состав: постер, название, год и все жанры. На широком экране постер 5:4 расположен над текстом. На узком миниатюра 104 × 83 px находится слева от названия и метаданных. Название и жанры могут переноситься; строка растёт по высоте. Без постера — нейтральная иллюстрация тех же пропорций, без года — «Год неизвестен», без жанров — «Без жанра».

Карточка — элемент списка. Постер с повторяющей название информацией имеет пустой альтернативный текст. Иллюстрации макета заменяются изображениями результата; их цвета не входят в палитру управления.

## PageNav

Страница соответствует трём последовательным карточкам. Нумерация находится рядом со счётчиком выдачи; при длинном списке панель остаётся сверху при прокрутке. Если страниц меньше двух, панель номеров скрыта. Счётчик выдачи всегда относится к выбранному жанру, а не к числу уже раскрытых карточек.

Номер работает как ссылка на начало группы. При прямом переходе к ещё не показанной группе сначала раскрываются недостающие группы, затем первая карточка целевой группы оказывается под панелью. Фокус при клавиатурном переходе перемещается на начало группы. При ручной прокрутке меняется только активный номер. Текущей ссылке задать `aria-current="page"`; например, доступное имя «Страница 2».

При большом числе страниц показывать первую, последнюю и соседние с текущей; пропуск обозначать неинтерактивным многоточием. На узком экране блок номеров при необходимости переносится под счётчик. Каждый номер имеет цель не меньше 44 × 44 px.

## ListBoundary

При движении вниз у нижней границы раскрывается следующая тройка. Уже показанные карточки сохраняют порядок и позицию. Если список изначально короче окна, движение вниз колесом, жестом или клавишей также открывает следующую группу; остаётся доступен и явный переход по номеру.

Ожидание → «Загружаем следующую страницу…» под карточками. При мгновенной локальной нарезке индикатор не задерживает выдачу. Конец → «Показаны все результаты». После конца новые группы не создаются. Строка состояния не является кнопкой.

## QueryFeedback

| Состояние                 | Представление                                                                                           |
| ------------------------- | ------------------------------------------------------------------------------------------------------- |
| Первый запрос выполняется | «Ищем сериалы…» и три нейтральных силуэта карточек.                                                     |
| Нет совпадений            | «Ничего не найдено» и предложение изменить название; поле остаётся заполненным, фильтр и номера скрыты. |
| Ошибка получения          | «Не удалось загрузить», пояснение и кнопка «Повторить» для того же запроса.                             |

Обновление количества и статуса озвучивается через `role="status"`; ошибка — через `role="alert"`. Декоративные силуэты и знаки не озвучиваются. Фокус виден на всех интерактивных элементах; при уменьшенном движении — без мерцания и плавного скролла.

## Адаптация

От 1024 px — сетка из трёх равных колонок с промежутками 24 px, максимальная ширина содержимого 1296 px. Ниже 1024 px — список компактных карточек, три строки в группе. Ниже 768 px поле переходит под заголовок. Боковые поля уменьшаются до 20 px; теги переносятся целиком. На ширине 320 px длинные названия, жанры и панель номеров могут занимать несколько строк.
