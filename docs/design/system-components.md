## Экран восстановления

Общая граница ошибок React (`ErrorBoundary`) оборачивает приложение. При исключении в рендере дочернего экрана она заменяет его самостоятельным запасным экраном. На широком экране сообщение и кнопка находятся слева от иллюстрации с телевизором. На телефоне блоки располагаются в одну колонку. Заголовок получает фокус, следующей по Tab доступна кнопка. Иллюстрация декоративная. [Настольный экран](screens/17-recovery.svg) · [Мобильные состояния](screens/23-recovery-sizes.svg).

«Восстановить» запускает одну попытку сбросить ошибку и заново открыть каталог с пустым поиском. Пока попытка выполняется, повторное нажатие заблокировано. После успеха фокус переходит в поле поиска. Если рендер снова завершился ошибкой, кнопка снова доступна. Язык и тема сохраняются. Ошибки получения результатов обрабатывает компонент поиска с действием «Повторить».

## Notification

Уведомление появляется поверх приложения по центру верхнего края окна. Максимальная ширина 480 px. Отступ сверху 24 px на компьютере, 12 px плюс безопасная область на телефоне. На узком экране ширина равна ширине окна за вычетом 16 px с каждой стороны. Текст переносится, высота сообщения растёт. [Положение на экране](screens/21-notification-placement.svg).

| Вид     | Цвет и знак                                      | Закрытие                   | Озвучивание                |
| ------- | ------------------------------------------------ | -------------------------- | -------------------------- |
| Error   | Красный, восьмиугольник с восклицательным знаком | Вручную                    | Срочное, `role="alert"`    |
| Warning | Жёлто-оранжевый, треугольник                     | Вручную                    | Спокойное, `role="status"` |
| Success | Зелёный, галочка в круге                         | Вручную или через 6 секунд | Спокойное, `role="status"` |
| Info    | Серый, буква i в круге                           | Вручную или через 6 секунд | Спокойное, `role="status"` |

Одновременно показывается одно сообщение. Разные события ожидают своей очереди, повтор того же активного события объединяется с текущим. Крестик имеет доступное имя и область нажатия 44 × 44 px. Уведомление сохраняет фокус на текущем действии пользователя. Таймер приостанавливается при наведении или фокусе внутри уведомления. При закрытии с клавиатуры фокус возвращается к прежнему доступному элементу. [Светлые и тёмные варианты](screens/20-notifications.svg) · [Значения для реализации](notification-tokens.json).

## Тема

До ручного выбора палитру задаёт системная настройка `prefers-color-scheme`. Кнопка с луной или солнцем переключает тему и сохраняет выбор. При смене темы интерфейс перекрашивает открытый экран с сохранением запроса, жанра, страницы и фокуса. Компоненты используют одинаковые имена цветовых токенов в обеих темах. Цвета постеров берутся из самих изображений. [Светлые значения](tokens.json) · [Тёмные значения](dark-colors.json) · [Тёмная выдача](screens/11-dark-results.svg).

## Иконка

Два сливовых треугольника расположены на лавандовой плитке. Просвет между ними сохраняется на размере 16 px. Для вкладки доступны [SVG со скруглениями](icons/app-icon.svg) и [ICO с растрами 16, 32 и 48 px](icons/favicon.ico). Для системного ярлыка предусмотрена [квадратная основа](icons/app-icon-square.svg) и непрозрачные [PNG 192](icons/icon-192.png) и [PNG 512](icons/icon-512.png). [Примеры в контексте](screens/22-app-icon.svg).

## Текст для словарей

Название Season One одинаково в обеих локалях. Для приложения потребуются следующие строки.

| Элемент                    | Русский                                       | English                               |
| -------------------------- | --------------------------------------------- | ------------------------------------- |
| Заголовок запасного экрана | Не удалось показать экран                     | This screen couldn’t be displayed     |
| Пояснение                  | Можно начать поиск заново.                    | You can start a new search.           |
| Действие                   | Восстановить                                  | Restore                               |
| Закрытие уведомления       | Закрыть уведомление                           | Dismiss notification                  |
| Error                      | Ошибка · Не удалось обновить результаты.      | Error · Could not update the results. |
| Warning                    | Предупреждение · Соединение с сетью потеряно. | Warning · Network connection lost.    |
| Success                    | Успешно · Поиск восстановлен.                 | Success · Search restored.            |
| Info                       | Информация · Показана сохранённая выдача.     | Info · Showing saved results.         |
