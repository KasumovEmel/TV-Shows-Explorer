# Presenter

- Храни `usePresenter.ts` рядом с View. Возвращай готовые данные, флаги и обработчики. Состояние нескольких дочерних компонентов принадлежит ближайшему общему владельцу.
- Вызывай Task из обработчика или из хука загрузки. Хук хранит текущий результат и отменяет устаревшую загрузку. Загрузку, ошибку без данных и успешную пустую выдачу различай по фактам, которые получает Presenter.
- Presenter выбирает, нужен ли переход и куда. Router выполняет переход. Фокус, прокрутка и повтор запроса также принадлежат Presenter.
- Если хук объединяет несколько обязанностей, выдели одну по смыслу. Например, `useSearchQuery` управляет текстом и отменой поиска, а `useSearchPage` загружает страницу с текущими критериями.

Пример именования флагов для [Presenter выдачи](../src/app/SearchPage/Results/usePresenter.ts).

```ts
const isLoading = isEntering || (!data && !isFailed);
const isLoadError = isFailed && !isEntering;
const isEmpty = !isLoading && data?.items.length === 0;
```
