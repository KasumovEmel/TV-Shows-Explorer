# Entity / Store

- Entity описывает предметные данные. Объявляй тип у владельца. Добавляй Store, когда независимым частям UI нужно читать и менять общее клиентское состояние.
- Предоставляй операции чтения и записи. Загрузку и порядок действий размещай в Task. Текущий ответ сервера хранится у потребителя. Общий список избранного доступен через контекст React.
- Черновик, фокус и состояние отдельного экрана держи в Presenter или его хуке. Для нескольких потомков поднимай такое состояние к ближайшему общему владельцу.

| Данные                                                | Владелец в проекте                                                                                                                         |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Текст, который печатает пользователь                  | Локальный `useState` в [useSearchQuery](../src/app/SearchPage/logic/hooks/useSearchQuery.ts)                                               |
| Серверная выдача по названию, жанру и странице        | [useSearchPage](../src/app/SearchPage/search/logic/hooks/useSearchPage.ts) загружает текущую страницу. Presenter вычисляет флаги для View. |
| Избранное, которым пользуются поиск и отдельный экран | [useFavorites](../src/app/favorites/logic/hooks/useFavorites.ts) читает общий список из контекста и вызывает Tasks для изменений           |

```ts
const [value, setValue] = useState(''); // локальный ввод
const { data, isFailed, retry } = useSearchPage({ criteria, signal });
```
