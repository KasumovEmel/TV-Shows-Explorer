## Вызов и контракт

View импортирует свой `usePresenter`. Presenter может вызывать Task напрямую или через хук загрузки. Task принимает обычные данные и возвращает результат. Форму props и обработчиков определяют потребности View, форму входа и результата Task — её потребитель.

Например, для кнопки жанра Presenter готовит подпись, флаг `isSelected` и обработчик выбора. Логику выбора жанра и возврата к первой странице можно проверить отдельным вызовом `selectGenre({ criteria, genre })`.

## Учебный пример изменения автокомплита

Допустим, нужно добавить подсказки и показывать ошибку для неподдерживаемого языка. Это пример распределения новой задачи. Текущее поведение поиска описано в [дизайне SearchField](../../docs/design/components.md#searchfield).

| Владелец                         | Действие                                                                                                                                                              |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| View                             | Привяжи готовые `value` и `onChange`. Покажи переданные `options` и текст ошибки.                                                                                     |
| `usePresenter.ts`                | Проверь ввод, получи текст через `t()` и передай допустимый запрос или `null` в `useSuggestions`.                                                                     |
| `logic/hooks/useSuggestions.ts`  | При смене запроса и размонтировании отмени предыдущую загрузку. Для `null` отключи загрузку и верни пустой список. Применяй результат только для актуального запроса. |
| `logic/tasks/loadSuggestions.ts` | Прими `{ query, signal }`, передай сигнал операции API и верни варианты. Клиентский HTTP проходит через общий `request()`.                                            |

Проверка: введи «убить», затем «убить Билла». Поздний ответ на первый запрос должен оставить подсказки для второго. При смене ввода на неподдерживаемый язык поле показывает ошибку, список остаётся пустым.

Каждый файл правил и этот указатель укладывай в 120 строк, включая примеры и пустые строки.
