# TV Shows Explorer

Учебный проект курса Simple Architecture. Стартовый каталог читает `public/shows.json` через Axios и кеширует ответ с помощью SWR. Для запуска достаточно локального сервера.

## Запуск

Потребуются Node.js 22.12 или новее и pnpm 12.18.0. Из корня проекта:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открой адрес, напечатанный Rsbuild. Чтобы использовать закреплённую версию pnpm на машине со старым Corepack, запускай те же команды через npm:

```sh
npx --yes pnpm@12.18.0 install --frozen-lockfile
npx --yes pnpm@12.18.0 dev
```

## Команды

| Команда                                      | Назначение                                          |
| -------------------------------------------- | --------------------------------------------------- |
| `pnpm format`                                | Отформатировать файлы и проверить лимит в 120 строк |
| `pnpm check`                                 | Проверить формат, лимит строк, линтинг и типы       |
| `pnpm build`                                 | Проверить типы и собрать приложение в `dist/`       |
| `pnpm preview`                               | Открыть локальный сервер собранного приложения      |
| `pnpm exec openspec validate --all --strict` | Проверить спецификации и активные изменения         |

## Работа над заданием

Открой папку проекта в VS Code. Oxc включает форматирование при сохранении и диагностику. Расширение TypeScript 7 использует локальную версию TypeScript для автодополнения и навигации. Оба расширения перечислены в рекомендациях проекта. Вкладки одноимённых файлов получают подписи по родительской папке, например `Catalog/index`.

Добавляй правила для агентов в `.agents/rules/` отдельными Markdown-файлами. Корневой `AGENTS.md` указывает агентам читать их перед работой.

Для нового задания используй навык `$openspec-propose`, для реализации — `$openspec-apply-change`, для завершённого изменения — `$openspec-archive-change`. Действующие спецификации хранятся в `openspec/specs/`.
