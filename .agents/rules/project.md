# Правила проекта

- Используй строгий TypeScript и Rsbuild. Сохраняй React StrictMode в `src/app/App.tsx`.
- Следуй [правилам архитектуры](architecture.md) при выборе слоя VIPER и размещении компонентов и логики.
- Используй SWR для кеширования запросов и View Transitions API для переходов между экранами.
- Добавляй тексты интерфейса в английский и русский словари i18next. Английский загружается при запуске, русский — по требованию.
- Обрабатывай общие ошибки API в `AppSWRConfig` через `SWRConfig.onError`. Для HTTP 429 показывай предупреждение о лимите запросов, для остальных ошибок — общее уведомление.
- После изменений запусти `pnpm format`, затем `pnpm check`. Исправь оставшиеся ошибки.
