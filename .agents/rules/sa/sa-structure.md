# Структура проекта

Группируй код по владельцу. У компонента своя папка в PascalCase. View, её основной Presenter, публичные типы и стили лежат рядом. В JS/TS точка входа `index.ts` экспортирует публичные имена.

**Создавай папку категории вместе с первым файлом.** Первая функция нормализации сразу попадает в `logic/helpers/normalizeQuery.ts`. Остальные категории добавляй по мере необходимости.

| Папка у владельца | Что в ней лежит                                         | Пример                  |
| ----------------- | ------------------------------------------------------- | ----------------------- |
| `logic/tasks/`    | Пользовательский или предметный сценарий                | `selectGenre.ts`        |
| `logic/helpers/`  | Чистое преобразование входных данных                    | `normalizeQuery.ts`     |
| `logic/utils/`    | Техническая операция с возможным побочным эффектом      | `readPreference.ts`     |
| `logic/api/`      | Граница внешнего сервиса, запрос и формат ответа        | `requestSuggestions.ts` |
| `logic/types/`    | Именованные типы, внутренние для логики                 | `SearchCriteria.ts`     |
| `logic/hooks/`    | Вспомогательное поведение Presenter в проектах с хуками | `useSuggestions.ts`     |

- Для Task, helper и util используй один файл на функцию. Если сценарий разрастается, выдели именованные шаги по их назначению, сохрани один публичный вызов Task. [Имена и булевы флаги](sa-naming.md)
- Приватного потомка храни у родителя. Для двух потребителей выбери ближайшего общего владельца. Например, `MessageList/components/ReplyPreview/` доступен текстовым и голосовым сообщениям. Общие для разных экранов компоненты размещай в общей `components/`.
- Размещай Store у владельца общих данных, типы публичного контракта — у владельца контракта. Скелетон, стили и ресурсы одного компонента храни рядом с этим компонентом.
- Для серверного модуля действует то же правило владения. Например, `catalog/handlers/search.ts` принимает вход операции, `catalog/logic/tasks/searchCatalog.ts` выполняет сценарий, а `catalog/logic/api/requestCatalog.ts` обращается к источнику данных.
- Укладывай исходный файл в 120 строк. Отделяй законченный сценарий, преобразование или дочернее представление.

```text
SearchField/
├── index.ts
├── SearchField.tsx
├── usePresenter.ts
├── types.ts
├── styles.module.css
└── logic/
    ├── helpers/normalizeQuery.ts
    ├── hooks/useSuggestions.ts
    └── tasks/loadSuggestions.ts
```
