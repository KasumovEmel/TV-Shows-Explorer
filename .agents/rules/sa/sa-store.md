# Entity / Store

- Entity описывает предметные данные. Объявляй тип у владельца. Добавляй Store, когда независимым частям UI нужно читать и менять общее клиентское состояние.
- Предоставляй операции чтения и записи. Загрузку и порядок действий размещай в Task. Текущий ответ сервера хранится у потребителя. Presenter роутера передаёт общий снимок избранного обоим экранам через props.
- Черновик, фокус и состояние отдельного экрана держи в Presenter или его хуке. Для нескольких потомков поднимай такое состояние к ближайшему общему владельцу.

| Данные                                                | Владелец в проекте                                                                                                                                              |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Текст, который печатает пользователь                  | Локальный `useState` в [useSearchQuery](../../../apps/web/src/app/pages/SearchPage/logic/hooks/useSearchQuery.ts)                                               |
| Серверная выдача по названию, жанру и странице        | [useSearchPage](../../../apps/web/src/app/pages/SearchPage/search/logic/hooks/useSearchPage.ts) загружает текущую страницу. Presenter вычисляет флаги для View. |
| Избранное, которым пользуются поиск и отдельный экран | [useFavoriteList](../../../apps/web/src/app/logic/favorites/hooks/useFavoriteList.ts) хранит снимок для обоих экранов и вычисляет счётчик                       |

```ts
const [value, setValue] = useState(''); // локальный ввод
const { data, isFailed, retry } = useSearchPage({ criteria, signal });
```
