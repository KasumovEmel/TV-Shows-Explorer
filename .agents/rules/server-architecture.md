# Архитектура сервера

- Размещай код у владельца: `catalog/` отвечает за поиск сериалов, `favorites/` за сессии и избранное, `health/` за проверку готовности. Другие модули и тесты подключают публичные имена через `index.ts`.
- `app.ts` собирает приложение Hono и настраивает общие HTTP-ошибки. `index.ts` открывает базу, запускает сервер и освобождает ресурсы. Передавай зависимости обработчикам через типизированный контекст.
- Одна операция HTTP — один одноимённый обработчик. Обработчик принимает проверенные параметры и переводит результат в HTTP-ответ. `operations.ts` только экспортирует реализации для Orval. Изменяй контракт в `packages/contracts/`, сохраняй воспроизводимость генерации.
- Сценарий работает с обычными аргументами без Hono. Например, `saveFavorite` проверяет наличие записи до обращения к каталогу, а уникальность при одновременной записи гарантирует SQLite. Размещай сценарии и чистые преобразования в `logic/` по тем же правилам категорий, что и на клиенте: одна функция — один одноимённый файл.
- Внешний HTTP и формат TVmaze принадлежат адаптеру каталога, SQL — хранилищу избранного. Внедряй транспорт, часы и путь к БД там, где тесту нужно управлять ответом, сроком или данными. Проверяй кеш, пагинацию и сохранение снимков без доступа к реальному TVmaze.
