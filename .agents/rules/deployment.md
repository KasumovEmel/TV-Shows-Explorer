# Публикация

- Перед настройкой VPS сверь DNS и ключ SSH-хоста. Проверь firewall, занятые порты и подключение к VPN. Для HTTPS используй действующий TLS-прокси или свободный порт. Выпусти сертификат и выполни `nginx -t` перед перезагрузкой конфигурации.
- Установи Node.js 24.22.2 или новее и SQLite CLI. Включи службу из `deploy/season-one.service`. В `/srv/season-one/` дай пользователю `season-one` запись в `data/`, nginx — чтение `current/web/`. Пользователю деплоя разреши переключать релизы, создавать бэкап и перезапускать или останавливать службу через `sudo -n`.
- В окружении GitHub Actions `production` задай `SITE_URL` и параметры SSH из `.github/workflows/release.yml`. Для `VPS_KNOWN_HOSTS` используй проверенный ключ хоста.
- Для публикации запусти `Release` вручную или отправь тег `release-*`. Храни базу и проверенную копию `backups/latest.sqlite` вне каталога релизов. Сохраняй совместимость схемы с предыдущим API.
- После релиза проверь поиск, сохранённое избранное, изоляцию профилей и VPN. Откат проверяй на стенде с ошибкой `/api/health`. После возврата сверь `/revision.txt` и заголовок API `X-Release-Revision` с SHA предыдущего релиза.
