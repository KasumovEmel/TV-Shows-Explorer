# Публикация

- Перед настройкой VPS сверь DNS и ключ SSH-хоста. Проверь firewall, занятые порты и подключение к VPN. Для HTTPS используй действующий TLS-прокси или свободный порт. Выпусти сертификат и выполни `nginx -t` перед перезагрузкой конфигурации.
- Установи Node.js 24.22.2 или новее и включи службу из `deploy/season-one.service`. При обновлении установленного unit выполни `systemctl daemon-reload`. Дай nginx чтение `/srv/season-one/current/web/`. Пользователю деплоя разреши переключать релизы, перезапускать и останавливать службу через `sudo -n`.
- В окружении GitHub Actions `production` задай `SITE_URL` и параметры SSH из `.github/workflows/release.yml`. Для `VPS_KNOWN_HOSTS` используй проверенный ключ хоста.
- Для публикации запусти `Release` вручную или отправь тег `release-*`. Каждый запуск API начинает с пустых сессий, избранного и кеша каталога. Оставь файлы данных и резервные копии прежних релизов на месте.
- После релиза найди сериал, добавь его в избранное, проверь список из двух профилей и доступность VPN. Откат проверяй на стенде с ошибкой `/api/health`. После возврата сверь `/revision.txt` и заголовок API `X-Release-Revision` с SHA предыдущего релиза.
