# Архитектура React-компонентов

**Строй дерево папок по экрану.** Если часть интерфейса принадлежит одному компоненту, положи её в его папку `components/`. На каждом уровне действует то же правило. Например, в мессенджере список чатов и открытый чат — соседние части экрана, а кнопка стикеров принадлежит нижней панели:

```text
Messenger/components/
├── Chats/
└── ActiveChat/components/
    └── BottomPanel/components/
        └── StickerPackIcon/
```

**Один компонент — одна папка.** Имя папки и имя View совпадают с именем компонента в PascalCase. Например, папка `SearchBar/` содержит:

| Файл                | Ответственность                                                                                                                                      |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SearchBar.tsx`     | View вызывает `usePresenter(props)` и рисует JSX по его результату. Для событий привязывает готовые обработчики.                                     |
| `usePresenter.ts`   | Хук принимает пропсы и возвращает данные, флаги и обработчики для View. Здесь живёт вся логика компонента: состояние, эффекты, запросы и вычисления. |
| `types.ts`          | Все типы компонента, включая типы пропсов.                                                                                                           |
| `styles.module.css` | Стили компонента.                                                                                                                                    |
| `index.ts`          | Публичные экспорты: компонент и нужные снаружи типы.                                                                                                 |

**Вспомогательный код держи рядом с владельцем.** Создавай `helpers/` и `utils/` по необходимости. В `helpers/` клади только чистые функции: результат зависит от аргументов, побочных эффектов нет. Функции в `utils/` могут иметь побочные эффекты и вызывать хелперы. В обеих папках одна функция — один файл с её именем, например `helpers/formatDate.ts`.

**Общее выноси в `src/shared/`.** Переиспользуемые элементы (`Button`, `Text`, `Input`, `List`, `Card`) храни в `shared/components/` по тем же правилам. Общие функции храни в `shared/helpers/` и `shared/utils/`.

**Импорты идут вниз по дереву или в `shared`.** Родитель подключает дочерний компонент через его `index.ts`. Компонент использует свои локальные файлы, но не импортирует родителя, соседнюю ветку или внутренние файлы другого компонента. Код в `shared` не зависит от экранов.
